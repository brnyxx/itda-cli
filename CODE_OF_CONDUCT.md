# Code of conduct

This project is a small one, and the rules are short.

- Be plain and be kind. Say what is wrong with the code, not with the person.
- Assume the other person is trying to help, because almost everyone is.
- No harassment, insults, slurs or unwelcome attention, in issues, pull
  requests, discussions or anywhere else the project meets.
- Private data stays private. Do not post other people's credentials, cookies
  or site data, even when they are the subject of a bug.

If someone breaks these rules, write to the maintainer through GitHub's
**Report content** button or a private message. Reports are read by the
maintainer only. A first problem gets a warning; a repeated or serious one gets
the person removed from the project's spaces.

These rules apply to everyone, including the maintainer.
