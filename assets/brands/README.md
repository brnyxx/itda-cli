# Brand marks

Logos of the services that have a ready-made site in [sites/](../../sites/),
used only to show which site a definition talks to. Each mark is the owner's
trademark; itda is not affiliated with or endorsed by any of them.

| File | Mark | Color | Owner's guidelines | Path source and license |
|---|---|---|---|---|
| `github.svg` | GitHub Invertocat | `#181717` | <https://github.com/logos> | [Simple Icons](https://simpleicons.org) 16.35.0, CC0-1.0 |
| `npm.svg` | npm | `#CB3837` | <https://docs.npmjs.com/policies/logos-and-usage> | Simple Icons 16.35.0, CC0-1.0 |
| `pypi.svg` | PyPI | `#3775A9` | <https://pypi.org> | Simple Icons 16.35.0, CC0-1.0 |
| `crates-io.svg` | Rust (crates.io is the Rust project's registry) | `#000000` | <https://www.rust-lang.org/policies/media-guide> | Simple Icons 16.35.0, CC-BY-SA-4.0, Rust Foundation |

Each file places the unmodified mark in its own color on a white rounded
tile, so it reads on light and dark backgrounds.
